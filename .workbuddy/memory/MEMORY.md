# 青芽BUD 项目长期记忆

## 项目定位

青芽BUD：正向行为引导电子疗愈宠物小程序/APP。用户通过早睡早起、做好事、做公益、运动等正向行为获得喂养青芽的道具；情绪低落或自我伤害时，青芽会状态变差并温柔安抚、正确引导。
